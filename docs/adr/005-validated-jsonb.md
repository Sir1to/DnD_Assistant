# ADR-005: ограниченный JSONB для виджетов

Статус: принято.

Небольшие расширяемые `config` и `state` хранятся в JSONB, но валидируются Zod-схемой
конкретного типа и версией. Кампании, членство, размещения и бои остаются
нормализованными. Это даёт расширяемость без непрозрачного «JSON приложения».
